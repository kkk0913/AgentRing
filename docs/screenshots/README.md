# README screenshots

Updated for the 0.2.0 UI. Both READMEs use these screenshots:

- `menubar-popover.png`: Codex and Cursor account columns, rings, refresh and settings buttons.
- `settings-general.png`: native sidebar and current General settings.
- `settings-auth.png`: provider checkboxes, independent account toggles, and reordering controls.

These images are rendered from the real SwiftUI views in an isolated preview app with Bundle ID `app.agentring.ReadmePreview`. All accounts and quota values are demo data. No production credentials or account identifiers are used. The preview does not start network polling.

For future updates, capture the current views using demo accounts. Keep the full pane width, avoid keyboard-focus highlights, and verify that no credentials or personal information appear before committing the images.
